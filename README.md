# Cinematic Fight Prompt

中文高燃打斗提示词 Skill，面向 AI 生图、图生视频和 AI 漫剧分镜。

它把角色/对象提示词转成连续战斗设计，重点处理：

- 视觉核心与华丽大招
- 冲击帧 Impact Frame
- 黑洞斩、巨兽核心、法阵和能量碰撞
- 运镜、动作链、受力结果和环境反馈
- 随机创作与固定角色/场景输入
- 15 秒短片、30 秒完整分镜

## 使用

将 `.codex/skills/cinematic-fight-prompt/SKILL.md` 放入支持 Skill 的工作区中，并提出你的需求。

固定输入时可以提供任意角色或对象，不限 MJ，也不限定男女角色：

```text
角色A提示词：...
角色B提示词：...
场景提示词：...
我想设计一段 15 秒的高燃打斗，主视觉是黑洞斩。
```

没有固定角色和场景时，可以要求随机生成。
